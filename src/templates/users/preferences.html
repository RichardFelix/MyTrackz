Preferences

Customize the look and behavior of the application.

{% csrf_token %} {# Theme #}
{% include "app/icons/moon.svg" with classes="w-5 h-5 mr-2" %} Theme

Choose between the dark theme (black background) and the grey theme (dark grey background).

{# Home Layout #}
{% include "app/icons/four-square.svg" with classes="w-5 h-5 mr-2" %} Compact home list

Show home screen items in a compact poster list. Swipe an in-progress item left or right to mark the next unit watched. Turn this off to restore the card layout.

{# Grid Progress Button Colors #}
{% include "app/icons/checkmark.svg" with classes="w-5 h-5 mr-2" %} Colored grid progress buttons

Show red and green backgrounds on the decrease and increase buttons in the home card grid. Turn this off for the original neutral buttons.

{# Media Card Overlay #}
{% include "app/icons/image.svg" with classes="w-5 h-5 mr-2" %} Hide Hover Overlay on Touch Devices

Hide the media card hover overlay with action buttons on touch devices for a cleaner mobile experience. On desktop, the overlay will still appear when you hover your mouse over media cards.

{# Obfuscate Unseen Episodes #}
{% include "app/icons/eye.svg" with classes="w-5 h-5 mr-2" %} Obfuscate Unseen Episodes

When enabled, unseen episode images and descriptions will be blurred.

{# Quick Watch Date #}
{% include "app/icons/clock.svg" with classes="w-5 h-5 mr-2" %} Bulk Completion Date

When marking a TV show or season as completed, its episodes will be marked as completed with this date.

{# Progress bar #}
{% include "app/icons/minus.svg" with classes="w-5 h-5 mr-2" %} Show progress bar on media items

Display a progress bar on media items. Items which don't have max progress will be using a dotted line.

{# Hide Completed Recommendations #}
{% include "app/icons/circle-check.svg" with classes="w-5 h-5 mr-2" %} Hide completed media in recommendations

Hide media you've already completed from the recommendations section on detail pages.

{# Hide Zero Ratings #}
{% include "app/icons/star.svg" with classes="w-5 h-5 mr-2" %} Hide zero ratings

Hide the rating badge from media cards when the rating is zero.

{# Continue the Story #}
{% include "app/icons/book-open.svg" with classes="w-5 h-5 mr-2" %} Show Continue the Story section

Show the Continue the Story section on the home page, suggesting direct follow-ups (sequels, next in series, expansions) to media you've watched, read or played.

{# Date Format #}
{% include "app/icons/calendar.svg" with classes="w-5 h-5 mr-2" %} Date Format

Choose how dates are displayed throughout the application.

{# Time Format #}
{% include "app/icons/clock.svg" with classes="w-5 h-5 mr-2" %} Time Format

Choose between 12-hour or 24-hour clock display.

{# Week Start Day #}
{% include "app/icons/week.svg" with classes="w-5 h-5 mr-2" %} Week Start Day

Choose which day the week starts on for calendars and statistics.

{# Watch Provider Region #}
{% include "app/icons/globe.svg" with classes="w-5 h-5 mr-2" %} Watch provider region

Choose the region to show watch providers for. Setting this to disabled will hide the box from the media page.
